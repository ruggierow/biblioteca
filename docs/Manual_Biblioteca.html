1. Instalação

O programa é distribuído como uma interface web (arquivo biblioteca.html) que abre diretamente no navegador — sem instalação de software. Há dois pacotes ZIP, um para cada sistema operacional, com o HTML, um lançador e os demais recursos necessários.

1.1 Instalação no macOS

  1. Baixe o arquivo Biblioteca-Web-Mac.zip.
  2. Faça duplo clique no ZIP para extrair — uma pasta com os arquivos do programa aparece.
  3. Abra a pasta extraída e faça duplo clique em Abrir Biblioteca.command.

Pasta Biblioteca-Web-Mac

📄  Abrir Biblioteca.command
📄  Instalar no Desktop.command  (executar uma vez)
🌐  biblioteca.html
📖  Manual_Biblioteca.pdf
📊  Obras e Autores 2017-2026.xlsx
  1. Na primeira abertura, o macOS pode exibir um aviso de segurança. Para contorná-lo:
  1. Clique com o botão direito em Abrir Biblioteca.command.
  2. Escolha Abrir no menu de contexto.
  3. Clique em Abrir na caixa de diálogo que aparece.

A partir da segunda abertura, basta dar duplo clique normalmente.

ℹ️ Os dados ficam salvos automaticamente no navegador (localStorage). Use Vincular biblioteca.txt (seção Arquivo) para que as alterações sejam gravadas também em arquivo.
💡 Ícone no Desktop: clique com o botão direito em Instalar no Desktop.command → Abrir. Um ícone Biblioteca 📚 é criado na área de trabalho. Execute este script novamente sempre que instalar uma versão nova — o ícone será atualizado automaticamente.

1.2 Instalação no Windows

  1. Baixe o arquivo Biblioteca-Web-Windows.zip.
  2. Clique com o botão direito no ZIP → Extrair Tudo… → escolha uma pasta definitiva (ex.: C:\Biblioteca\). Não execute diretamente do ZIP.
  3. Abra a pasta extraída e faça duplo clique em Criar Atalho no Desktop.bat.

Um atalho chamado Biblioteca (com ícone de livro) é criado automaticamente no Desktop. A partir daí, use esse atalho para abrir o programa.

ℹ️ Na primeira execução, o Windows pode exibir um aviso do SmartScreen. Clique em Mais informações → Executar mesmo assim.
💡 Os dados ficam salvos automaticamente no navegador (localStorage). Use Vincular biblioteca.txt (seção Arquivo) para que as alterações sejam gravadas também em arquivo.

2. Visão Geral do Sistema

O Sistema de Gestão de Biblioteca é uma aplicação para catalogar e gerenciar uma coleção particular de livros. Existe em dois formatos complementares:

  • Interface Web (arquivo biblioteca.html) — abre diretamente no navegador, sem instalação. Disponível para macOS e Windows.
  • Programa em C++ (terminal) — versão de linha de comando para macOS, com persistência automática em arquivo biblioteca.txt.

Ambas as versões compartilham o mesmo arquivo de dados (biblioteca.txt) no formato TSV, podendo ser usadas alternadamente.

Campos de cada livro

TítuloNome completo do livro.
AutorNome do autor. Vários autores separados por ponto-e-vírgula.
TemaGênero ou assunto (ex.: Romance, Poesia, Ciência).
AnoAno de publicação da edição.
StatusDisponível ou Emprestado.
ComentáriosNotas livres sobre o livro (opcional).
LocalLocalização física na estante (opcional).
Grupo de LiteraturaIndica se o livro foi discutido num grupo de estudos.

3. Primeiro Uso

Ao abrir o programa pela primeira vez — quando ainda não há livros cadastrados e nenhum arquivo vinculado — uma tela de boas-vindas é exibida automaticamente, guiando o usuário na configuração inicial.

📚 Bem-vindo ao Sistema de Biblioteca!

Primeira abertura detectada. Como deseja armazenar seus livros?

📁
Selecionar ou criar arquivo
Escolhe onde salvar o biblioteca.txt no seu computador. Recomendado.
📥
Importar arquivo existente
Já tem um biblioteca.txt de outra instalação? Importe-o aqui.
⏭
Decidir depois
Os dados ficam salvos apenas no navegador. Você pode vincular um arquivo a qualquer momento.

💡 O arquivo biblioteca.txt é compatível com o programa em C++ e pode ser usado nos dois.

Opção 1 — Selecionar ou criar arquivo (recomendado)

  1. Clique em Selecionar ou criar arquivo.
  2. Um diálogo do sistema operacional se abre. Navegue até a pasta desejada (ex.: Documentos).
  3. Digite biblioteca.txt no campo de nome e clique em Salvar (ou selecione um arquivo já existente).
  4. A partir desse momento, todas as alterações são salvas automaticamente nesse arquivo.

Opção 2 — Importar arquivo existente

Use esta opção se já possui um biblioteca.txt de outra instalação do programa (versão web ou C++). O arquivo será carregado e seus livros aparecerão na lista imediatamente.

Opção 3 — Decidir depois

O programa funciona normalmente com os dados salvos apenas no navegador (localStorage). Você pode vincular um arquivo a qualquer momento clicando em Vincular biblioteca.txt na seção Importar / Exportar.

ℹ️ Esta tela de boas-vindas aparece somente na primeira abertura. Nas aberturas seguintes, o programa carrega diretamente com os dados já existentes.
💡 Programa C++: Na versão de terminal para macOS, não há tela de primeiro uso — o arquivo biblioteca.txt é criado automaticamente ao cadastrar o primeiro livro.

5. Cadastrar um Livro

Para adicionar um novo livro ao catálogo, preencha os quatro campos obrigatórios e clique em Cadastrar.

  1. Escreva o Título completo do livro.
  2. Escreva o Autor. Para vários autores, separe com ponto-e-vírgula: Autor A; Autor B.
  3. Indique o Tema (gênero literário, área do conhecimento, etc.).
  4. Indique o Ano de publicação.
  5. Clique em Cadastrar. O livro aparecerá imediatamente na lista.

7. Pesquisar e Filtrar

Use a barra de pesquisa para encontrar livros por qualquer combinação de critérios. A pesquisa é insensível a maiúsculas e aceita trechos parciais.

  1. Preencha um ou mais campos de filtro (Título, Autor, Tema, Status).
  2. Clique em Pesquisar ou pressione Enter em qualquer campo.
  3. A lista se atualiza mostrando apenas os livros que correspondem.
  4. Clique em Limpar filtros para voltar à lista completa.

10. Importar e Exportar

Os dados podem ser trocados com outras aplicações (incluindo o programa em C++) através do formato TSV.

Importar / Exportar

O formato é idêntico ao usado pelo programa em C++: campos separados por TAB e flag 1/0 para emprestado.

Backup

O botão Backup salva uma cópia do arquivo com a data e hora no nome, sem substituir o arquivo principal.

O nome do arquivo gerado inclui data e hora: biblioteca_2026-06-29_14h30.txt.

Versão O que acontece

💡 Faça backup antes de importar um arquivo novo ou de usar Apagar tudo.

Exportar

Clique em Exportar biblioteca.txt. O arquivo biblioteca.txt é baixado para a pasta Downloads do navegador. Mova-o depois para a pasta desejada, se necessário.

Importar

  1. Clique em Importar biblioteca.txt.
  2. Seleccione o arquivo biblioteca.txt no seu computador.
  3. O sistema pergunta se deseja substituir a lista atual ou adicionar ao final.
ℹ️ Compatibilidade: O arquivo TSV é compartilhado com o programa C++ (main.cpp). Pode usar os dois alternadamente: edite pelo navegador e depois continue pelo terminal, ou vice-versa.

11. Remover um Livro

Para excluir permanentemente um livro do catálogo:

  1. Localize o livro na lista.
  2. Clique no botão .
  3. Confirme a remoção na caixa de diálogo que aparece.
⚠️ Atenção: A remoção é permanente e não pode ser desfeita. Se tiver dúvidas, exporte o arquivo antes de remover.

Apagar toda a biblioteca

O botão Apagar tudo na seção Importar / Exportar exclui todos os livros de uma vez. Uma confirmação é pedida antes de executar esta ação.

12. Compatibilidade com Navegadores

A interface web (biblioteca.html) pode ser aberta diretamente em qualquer navegador moderno. Porém, há diferenças de comportamento importantes dependendo do navegador usado.

Função Chrome / Edge Firefox Safari
Cadastrar, pesquisar, editar✅✅✅
Salvar dados no navegador (localStorage)✅✅✅
Importar / Exportar arquivo TSV✅✅✅
Vincular arquivo (salvar automaticamente)✅✅✅ (Safari 15.2+)
Lembrar arquivo vinculado entre sessões✅✅⚠️ Não funciona
Botão Encerrar (fecha a aba)✅✅⚠️ Não fecha

Limitações do Safari — Detalhes

⚠️ Botão Encerrar não fecha a aba no Safari: por regra de segurança, o Safari só permite que um script feche uma aba que ele mesmo abriu. Como o usuário abre o arquivo diretamente, o botão Encerrar exibe a tela "Interface encerrada" mas a aba permanece aberta. Basta fechar manualmente com ⌘ W.
⚠️ Vínculo de arquivo não é lembrado entre sessões no Safari: o programa usa o IndexedDB do navegador para memorizar o arquivo biblioteca.txt vinculado. O Safari bloqueia o IndexedDB quando o arquivo é aberto via file:// (protocolo de arquivo local), por razões de privacidade. Na prática, a cada vez que abrir o programa no Safari será necessário clicar em Vincular arquivo novamente.

Recomendação

Para uso com a interface web, a ordem de preferência de navegadores é:

  1. Google Chrome ou Microsoft Edge — todas as funções disponíveis, incluindo vínculo automático de arquivo.
  2. Firefox — todas as funções básicas funcionam; o vínculo de arquivo também é suportado.
  3. Safari — funciona para uso básico, mas o botão Encerrar não fecha a aba e o vínculo de arquivo precisa ser refeito a cada sessão.

13. Formato do Arquivo de Dados

Os dados são salvos em biblioteca.txt no formato TSV (campos separados por tabulação). Cada linha representa um livro com 8 colunas:

Dom Casmurro → Machado de Assis → Romance Brasileiro → 1899 → 0 → → → 0
Sagarana → João Guimarães Rosa → Regionalismo → 1946 → 1 → Exemplar dedicado → Estante 2 → 1

(As setas → representam caracteres TAB reais no arquivo)

ColunaConteúdoExemplo
1TítuloDom Casmurro
2AutorMachado de Assis
3TemaRomance Brasileiro
4Ano1899
5Emprestado (1=sim, 0=não)0
6Comentários (opcional)Exemplar dedicado
7Local (opcional)Estante 2
8Grupo de Literatura (1=sim, 0=não)1

O arquivo pode ser editado diretamente num editor de texto ou numa folha de cálculo (Excel, Numbers) usando TAB como separador.
